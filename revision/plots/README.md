# Plots

Figures generated for the revision.

* `fig2_violin_bpress.png`: violin plot of button press counts by condition and repetition (high salience)
* `fig2_violin_sal_cond.png`: violin plot of button presses by salience and condition
* `fig3_isc_bar.png`: ISC bar plot (unthresholded mean ISC, all conditions)
* `fig3_isc_bar_nolabel2.png`: ISC bar plot with y-axis label removed from second panel
* `fig3_isc_violin.png`: ISC violin plot
* `fig_sigvox_bar.png`: significant voxel count bar plot (thresholded ISC)
* `connectivity_transitions.png`: within-subject functional connectivity matrices across runs (all conditions combined)
* `connectivity_transitions_by_condition.png`: connectivity transition matrices by attention condition
* `connectivity_transitions_by_condition_v2.png`: same as above with black outlines on significant cells, no grey overlay
* `region_isc_delta_heatmap.png`: heatmap of ISC differences (run 4 minus run 1) across ROIs
* `button_press_temporal_distribution.png`: distribution of button presses across time within runs
* `engagement_scatter.png`: scatter plot of self-reported engagement by salience category
