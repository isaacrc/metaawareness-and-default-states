# Results

Numerical outputs from revision analyses, organized by analysis type.

* `button_press_temporal/`: button press timestamps and run-level summaries by movie
* `connectivity/`: within-subject functional connectivity matrices and permutation test outputs (`.npy` files, one per subject/contrast)
* `engagement_ratings/`: summary statistics for self-reported engagement ratings
* `power_and_effect_sizes/`: Cohen's d, R², and power calculations for all reported comparisons
* `region_isc/`: ISC values within anatomically defined ROIs
* `source_data/`: source data tables exported for all figures (`.csv`)
