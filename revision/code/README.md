# Scripts

* `analysis1_region_isc.py`: computes ISC within anatomically defined ROIs across runs and conditions
* `analysis2_connectivity_transition.py`: computes within-subject functional connectivity matrices and tests for condition/run differences; generates connectivity transition figures
* `analysis3_button_press_temporal.py`: extracts button press timestamps by movie and run for temporal analysis
* `analysis4_engagement_ratings.py`: loads and plots self-reported engagement ratings by salience category
* `analysis5_power_effect_sizes.py`: computes Cohen's d, R², and power estimates for behavioral and ISC results
* `analysis6_updated_figures.py`: regenerates and reformats all main figures for the revision (significant voxel count, ISC bar plots, violin plots)
* `analysis7_source_data.py`: exports source data tables for all figures
